# Mangrove coastal protection in Lamu County, Kenya

R code for the analyses in:

> Olima, C. O. *et al.* Assessing how biophysical and perceived coastal protection by mangroves align for Kenyan coastal communities. (in review)

The code models wind-wave exposure and wave attenuation by mangroves at five sites in Lamu County, Kenya, estimates wave attenuation service provision (WASP), quantifies uncertainty, and analyses a household survey of perceived coastal protection.

## Scripts

| Script | Content |
|---|---|
| `00_run_all.R` | Runs scripts 01–07 in order |
| `01_setup_and_inputs.R` | Packages, settings, study sites, mangrove extent and wind data |
| `02_fetch_and_wave_heights.R` | Fetch (ray-casting), SMB wave heights and directional wave exposure |
| `03_attenuation_and_WASP.R` | Mangrove belt width, wave attenuation and WASP (Table 1) |
| `04_Figure1_wind_and_fetch_roses.R` | Figure 1b–g |
| `05_monte_carlo_uncertainty.R` | Monte Carlo uncertainty analysis (5,000 iterations per site) |
| `06_sensitivity_analysis.R` | One-at-a-time sensitivity analysis of WASP |
| `07_uncertainty_figures.R` | Figures 2 and 3, Supplementary Figures 1 and 2 |
| `08_household_survey.R` | Figure 4 and Supplementary Table 2 (runs independently) |

Panel (a) of Figure 1 (study area map) was produced in ArcGIS and is not generated by this code.

## Requirements

R (version 4.4.3) with the packages `sf`, `tidyverse`, `lubridate`, `patchwork`, `scales`, `readxl`, `MASS`, `forcats` and `stringr`:

```r
install.packages(c("sf", "tidyverse", "lubridate", "patchwork", "scales",
                   "readxl", "MASS", "forcats", "stringr"))
```

## Input data

Place the input files in the repository root (the working directory):

| File | Description | Included |
|---|---|---|
| `Vector_data/lamu_coastline_polygon.shp` (and associated files) | Mangrove extent polygon for Lamu County, derived from Global Mangrove Watch v3.0 | Yes |
| `lamu_wind_2024_2025.csv` | Hourly wind records, Lamu station, January 2024 – August 2025 | No (see below) |
| `Survey_New.xlsx` | Anonymised household survey (161 respondents) | No (see below) |

**Wind data.** The wind records were obtained from the Kenya Meteorological Department (KMD) and cannot be redistributed. They can be requested from KMD. The scripts expect a CSV file with the columns `datetime` (day/month/year hour:minute), `wind_speed_mps` (m s⁻¹) and `wind_dir_deg` (degrees from true north).

**Survey data.** The anonymised survey data are available from the corresponding author on request. Script 08 expects the columns `village`, `education`, `land_owner`, `years_lived`, `experience_flooding`, `coast_protected` and `effectiveness_mangrove`.

## Running the analysis

1. Open the project in RStudio, or set the working directory to the repository root.
2. Run `00_run_all.R` for the wave model, uncertainty analysis and figures.
3. Run `08_household_survey.R` for the survey analysis.

Results are written to the working directory with the suffix set by `RUN_TAG` in `01_setup_and_inputs.R` (default `main`), and figures to `plots/<RUN_TAG>/`. Intermediate results are saved in `checkpoints/`, so scripts 02–07 can also be run individually after script 01.

## Notes

- Tidal inundation is set to 50% at all sites (TESSA M4, zone D) in `01_setup_and_inputs.R`.
- Random seeds are fixed (`set.seed(42)` in script 05, `set.seed(43)` in script 06), so results are reproducible.
- The Monte Carlo analysis and sensitivity analysis each take several minutes.
